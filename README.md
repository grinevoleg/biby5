# biby5 — торговый бот для Bybit (USDT-перпетуалы)

Система для коротких сделок маленькими суммами на USDT-перпетуалах Bybit
через v5 API. Стратегия — возврат к средней (mean reversion), построена
вокруг минимизации комиссий: входы и тейки только лимитными post-only
ордерами (мейкер 0.02%), рыночное исполнение (тейкер 0.055%) — только
стоп-лосс и тайм-стоп.

> **Важно и честно.** Ни одна стратегия не гарантирует «стабильный прирост
> депозита». Рынок меняется: параметры, прибыльные на бэктесте, могут
> перестать работать. Поэтому процесс такой: бэктест → 1–2 недели на
> демо-счёте → реальный счёт минимальной суммой и только при положительной
> статистике. Дневной лимит убытка и риск на сделку — главная защита.

## Стратегия

На ликвидных перпетуалах резкое отклонение цены от средней статистически
чаще откатывается назад, чем продолжается. Сигналы по закрытым 5-минутным
свечам:

- **Лонг**: закрытие ниже нижней полосы Боллинджера (20, 2.0) и RSI(14) ≤ 30,
  при этом SMA20 выше EMA200 (откуп провала в восходящем тренде).
- **Шорт**: зеркально — закрытие выше верхней полосы, RSI ≥ 70, SMA20 ниже EMA200.
- **Тейк**: средняя полоса (SMA20). **Стоп**: 1.5 × ATR(14) от входа.
  **Тайм-стоп**: 24 бара (2 часа) — короткие сделки, капитал не зависает.
- Сделка открывается, только если расстояние до тейка ≥ 0.25% и покрывает
  комиссии круга с трёхкратным запасом, а тейк/стоп ≥ 0.5.

### Экономика комиссий

| Рынок | Круг сделки | Вывод |
|---|---|---|
| Спот | 0.1% + 0.1% = **0.20%** | съедает короткие сделки |
| Перпетуалы, тейкер | 0.055% × 2 = **0.11%** | дорого для скальпинга |
| Перпетуалы, мейкер (наш путь) | 0.02% × 2 = **0.04%** | тейк 0.25%+ даёт запас 6× |

### Инструменты

По умолчанию SOLUSDT, XRPUSDT, DOGEUSDT — ликвидные, волатильные,
с маленьким минимальным лотом (подходят для депозита $100–500).
Список меняется в `config.yaml`.

### Риск-менеджмент

- риск на сделку: 1% рабочего капитала (расстояние до стопа);
- максимум 2 одновременные позиции, номинал позиции ≤ 30% капитала;
- дневной лимит убытка 3% — достигнут, новые входы запрещены до конца дня (UTC);
- ≤ 15 сделок в день; плечо 2x только как запас маржи — сайзинг идёт от риска;
- `equity_cap_usdt: 300` — позиции считаются от этой суммы, даже если на
  демо-счёте лежит 50 000 USDT: статистика демо переносима на реальный депозит.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env   # вписать API-ключи
```

**Ключи для демо**: bybit.com → переключить аккаунт на Demo Trading →
создать API-ключ в демо-кабинете (ключи демо и реала разные).
В `config.yaml` режим задаёт `exchange.demo: true/false`.

## Запуск

```bash
# бэктест на исторических данных (30 дней, инструменты из конфига)
python scripts/run_backtest.py --days 30

# бот (демо или реал — по флагу demo в config.yaml)
python -m bot.main

# статистика журнала сделок
python scripts/show_stats.py
```

Бот пишет лог в `logs/bot.log`, сделки — в SQLite `state/journal.db`.
Остановка Ctrl+C: невыполненные входные ордера снимаются; открытая позиция
остаётся под защитой биржевого стопа и подхватывается при рестарте.

## Запуск 24/7 на VPS (Docker)

Боту нужен постоянно работающий хост — подойдёт любой дешёвый VPS
(Ubuntu/Debian, хватит минимальной конфигурации за ~$5/мес):

```bash
# на свежем VPS
curl -fsSL https://get.docker.com | sh
git clone https://github.com/grinevoleg/biby5.git && cd biby5
cp .env.example .env && nano .env     # вписать API-ключи

docker compose up -d --build          # запуск
docker compose logs -f                # смотреть лог (Ctrl+C — выйти, бот работает)
docker compose down                   # остановка
```

`restart: unless-stopped` поднимает бота после падений и перезагрузки
сервера. Журнал сделок (`state/journal.db`) и логи (`logs/`) лежат на
хосте и переживают пересборку контейнера. Статистика:
`docker compose exec bot python scripts/show_stats.py`.

## Структура

```
bot/
  config.py      загрузка config.yaml + .env
  indicators.py  SMA, EMA, RSI, ATR, Bollinger (чистый Python)
  strategy.py    сигналы mean reversion с фильтром комиссий
  risk.py        сайзинг от риска, дневные лимиты
  exchange.py    обёртка pybit (v5, linear, demo/real)
  trader.py      автомат сделки: вход post-only → SL/TP → выход
  journal.py     журнал SQLite + статистика
  main.py        точка входа
backtest/        загрузка истории + консервативный бэктестер
scripts/         run_backtest.py, show_stats.py
tests/           28 оффлайн-тестов (pytest)
```

## Дорожная карта до реального счёта

1. `python scripts/run_backtest.py --days 60` — профит-фактор стабильно > 1.2?
   Если нет — крутить параметры в `config.yaml` (но осторожно с подгонкой).
2. 1–2 недели на демо. Сверить демо-статистику с бэктестом: winrate и средняя
   сделка близки — модель исполнения адекватна.
3. `demo: false`, ключи реального счёта, `equity_cap_usdt` = реальный депозит.
   Первую неделю — вполовину меньший `risk_per_trade_pct`.

## Отказ от ответственности

Код предоставлен для обучения и исследований. Торговля деривативами с плечом
может привести к потере всего депозита. Вы используете систему на свой риск.
